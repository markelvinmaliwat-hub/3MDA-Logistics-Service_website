SEE ALL EMAILS + ACTIVITY IN ONE GOOGLE SHEET

1. Create a new Google Sheet (any name, e.g. "Dashboard Activity Log").
2. In the sheet: Extensions > Apps Script. Delete the sample code and paste everything from Code.gs. Save.
3. Click Deploy > New deployment > type: Web app.
     Execute as: Me
     Who has access: Anyone
   Click Deploy and allow the permissions. Copy the Web app URL.
4. Open index.html (and pldt_dashboard.html) in Notepad. Press Ctrl+F and find:   const LOG_URL=''
   Paste your URL between the two quotes, e.g.   const LOG_URL='https://script.google.com/macros/s/XXXX/exec'
   Save both files.
5. Host/open the dashboard from these files. Every open, sign up, login, failed login, logout,
   record view, search and facility check now adds a row to the ACTIVITY LOG tab with the
   email, agent code, time, action and device.

Note: the claude.ai artifact link cannot send data to outside sites, so use the files in this zip.
