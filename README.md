# PLDT Subscriber Lookup Dashboard

Static dashboard (single `index.html`) built from `DATABASE_AUG_TO_OCT.xlsx`
(PLDT, RED, VALIDATORS and FACILITY CHECK sheets).

## Publish on GitHub Pages
1. Create a new repository on GitHub.
2. Upload `index.html`, `.nojekyll` and `README.md` to the repository root.
3. Go to **Settings -> Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
4. Your dashboard will be live at `https://<your-username>.github.io/<repo-name>/`.

## Updating the data
Re-generate `index.html` with the newest Excel file and replace it in the repository.
